Ten thousand Cents.

The number of Sets that can exist at any given time is capped by the scarcest Cent the Set requires.

A Patina Set needs a notable desert, and five hundred ninety-eight Cents carry one.

A Sig Set needs a significant desert: one hundred fifty.

A Spectrum Set needs a gold: sixty-nine.

A Fulls Set needs a full verdigris: fifteen.

A Full Spectrum Set needs a full gold: nine.

A Full Contamination Set needs scotch tape: seven.

And the nineteen-forties Set needs the only Cent dated nineteen forty-nine: one.

One Cent, and one collector at a time.

Every time a Cent changes hands, it can complete one Set and break another.
