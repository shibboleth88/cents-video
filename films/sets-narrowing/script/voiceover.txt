Ten thousand Cents.
The number of Sets that can exist at any given time is capped by the scarcest Cent the Set requires.
A Patina Set needs a notable desert, and 598 Cents carry one.
A Sig Set needs a significant desert: 150.
A Spectrum Set needs a gold: 69.
A Fulls Set needs a full verdigris: 15.
A Full Spectrum Set needs a full gold: 9.
A Full Contamination Set needs scotch tape: 7.
And the 1940s Set needs the only Cent dated 1949: 1.
One Cent, and one collector at a time.
Every time a Cent changes hands, it can complete one Set and break another.
